vastgrid は 4 つのパッケージからなります。

| パッケージ | 内容 |
| --- | --- |
| [`vastgrid`](https://www.npmjs.com/package/vastgrid) | React の `DataGrid` コンポーネント。`vastgrid-core` のものをすべて再エクスポートします。 |
| [`vastgrid-core`](https://www.npmjs.com/package/vastgrid-core) | 表のプロトコル、`ArraySource`・`RemoteSource`、行のキャッシュ、選択とスクロールの写像、書式。フレームワークに依存しません。 |
| [`vastgrid-duckdb`](https://www.npmjs.com/package/vastgrid-duckdb) | DuckDB を使う Node.js の表のサーバーと、Fetch API の要求の受け口。 |
| [`vastgrid-browser`](https://www.npmjs.com/package/vastgrid-browser) | ローカルのファイルと URL の Parquet（HTTP Range）を Web Worker で読みます。サーバーは不要です。 |

## 動作環境

- **`vastgrid`**: React 18 以降と、CSS の `light-dark()` に対応したブラウザー（Chrome・Edge 123、Firefox 120、Safari 17.5 以降）。
- **`vastgrid-duckdb`**: Node.js 20 以降。DuckDB のバイナリがある Linux（x64・arm64、glibc・musl）、macOS（x64・arm64）、Windows（x64・arm64）で動きます。
- **`vastgrid-browser`**: モジュールの Worker に対応したブラウザー（Chrome・Edge 80、Firefox 114、Safari 15 以降）。特別なヘッダー（COOP/COEP）は要りません。
- **`vastgrid-core`** は依存がなく、同じブラウザーと Node.js 20 以降で動きます。

## メモリ上のデータ

```bash
npm install vastgrid
```

グリッドには `TableSource` と高さを渡します。`ArraySource` は、すでにブラウザーにある行を持ちます。

```tsx
import { ArraySource, DataGrid } from "vastgrid";
import "vastgrid/styles.css";
import { useMemo } from "react";

export function People({ people }: { people: { name: string; born: number; field: string }[] }) {
  const source = useMemo(
    () =>
      new ArraySource({
        columns: ["name", "born", "field"],
        rows: people.map((person) => [person.name, person.born, person.field]),
      }),
    [people],
  );
  return (
    <div style={{ height: 600 }}>
      <DataGrid source={source} />
    </div>
  );
}
```

グリッドは親の要素いっぱいに広がるので、親に高さが必要です（固定の高さか、伸びる flex や grid の子要素）。ソースは表ごとに 1 回だけ作ってください。新しいソースを渡すと、グリッドを最初から作り直します。

`ArraySource` は並べ替え・絞り込み・集計を画面のスレッドで行います。数十万行までが目安です。オプションは[メモリ上のデータ](/ja/guides/in-memory/)を参照してください。

## サーバーのファイル

```bash
npm install vastgrid vastgrid-duckdb
```

サーバーは DuckDB でファイルを開き、グリッドの要求に答えます。受け口は Fetch API の `Request` を受け取るので、それを使うどのフレームワークでも動きます。

import path from "node:path";

const root = "/srv/data";
const engine = TableEngine.create({ allowedDirectories: [root], tempDirectory: "/tmp/vastgrid" });

    return file;
  },
});

ブラウザーでは、`RemoteSource` に受け口の URL とファイルを指定します。

```tsx
"use client";
import { DataGrid, RemoteSource } from "vastgrid";
import "vastgrid/styles.css";
import { useMemo } from "react";

export function Table({ file }: { file: string }) {
  const source = useMemo(() => new RemoteSource({ endpoint: "/api/table", ref: file }), [file]);
  return (
    <div style={{ height: 600 }}>
      <DataGrid source={source} />
    </div>
  );
}
```

`vastgrid-duckdb` が使う `@duckdb/node-api` はネイティブの拡張です。サーバーのバンドルに含めず、OS ごとのパッケージ（`@duckdb/node-bindings-<platform>`。macOS で約 120 MB）をサーバーと一緒に配布してください。エンジンのオプション、安全性、デプロイは[サーバーのファイル](/ja/guides/server/)で説明します。

## ブラウザーで開くファイル

サーバーがなくても、`vastgrid-browser` が利用者の選んだファイルや URL の Parquet を Web Worker で読みます。

```tsx
import { BrowserSource } from "vastgrid-browser";

const source = new BrowserSource({ file }); // URL なら { url: "https://example.com/data.parquet" }
<DataGrid source={source} locale="ja" />;
// 表示しなくなったら source.close()
```

対応する形式、URL でできること、Parquet の配信は[ブラウザーで開くファイル](/ja/guides/browser/)で説明します。
