グリッドは 1 つのパッケージで、データはエンジンから読みます。エンジンはデータのある場所で選びます。

| パッケージ | 内容 |
| --- | --- |
| [`vastgrid`](https://www.npmjs.com/package/vastgrid) | React の `DataGrid`・`GridProvider` とフック。`vastgrid/core` には React を使わないストアとトランスポート、`vastgrid/server` にはサーバーで最初の行を読む関数、`vastgrid/locales/<tag>` には言語ごとの文言があります。 |
| [`vastgrid-js`](https://www.npmjs.com/package/vastgrid-js) | ページか Web Worker の中で動くメモリエンジン。JavaScript の行、Arrow の表、CSV・TSV・JSON Lines・Excel のファイル、ディスク上や URL の Parquet を扱います。 |
| [`vastgrid-duckdb`](https://www.npmjs.com/package/vastgrid-duckdb) | Node.js の DuckDB のエンジン。どんな大きさのファイルも開け、HTTP の受け口が付いています。 |
| [`vastgrid-spec`](https://www.npmjs.com/package/vastgrid-spec) | コードにした仕様。型、コマンド、プランの検査、適合性のテストがあり、自作のエンジンで使います。 |
| [`vastgrid-sql`](https://www.npmjs.com/package/vastgrid-sql) | プランを DuckDB の SQL にします。DuckDB の上に自作のエンジンを作るときに使います。 |

同じグリッドは、コードを書かずにそのまま使える形でもあります。コマンド（`npx vastgrid-cli data.parquet`）、VS Code の拡張機能、チャットの中の MCP App、Jupyter のノートブックのウィジェットです。[アプリ](/ja/apps/overview/)を参照してください。

## 動作環境

- **`vastgrid`**: React 19.3 以降と、CSS の `light-dark()` に対応したブラウザー（Chrome・Edge 123、Firefox 120、Safari 17.5 以降）。React が要るのは `DataGrid` とフックだけで、`vastgrid/core` と `vastgrid/server` は React なしで動きます。
- **`vastgrid-js`**: 同じブラウザー（Web Worker で動かすにはモジュールの Worker に対応したもの）か、Node.js 20 以降。
- **`vastgrid-duckdb`**: Node.js 20 以降。DuckDB の Node.js のバインディングがある Linux（x64・arm64、glibc・musl）、macOS（x64・arm64）、Windows（x64・arm64）で動きます。

## メモリ上のデータ

```bash
npm install vastgrid vastgrid-js
```

エンジンとトランスポートはコンポーネントの外で一度だけ作り、グリッドには表の名前と高さを渡します。

```tsx
import { DataGrid, localTransport } from "vastgrid";
import "vastgrid/styles.css";
import { memoryEngine } from "vastgrid-js";

const transport = localTransport(
  memoryEngine({
    tables: {
      people: {
        columns: [
          { name: "name", type: "string" },
          { name: "born", type: "integer" },
          { name: "field", type: "string" },
        ],
        rows: [
          ["Ada Lovelace", 1815, "Mathematics"],
          ["Grace Hopper", 1906, "Computer science"],
        ],
      },
    },
  }),
);

export function App() {
  return <DataGrid transport={transport} table="people" style={{ height: 600 }} />;
}
```

- グリッドは親の高さか、渡した高さいっぱいに広がります。描くのは画面に見えている行だけです。
- メモリエンジンは、列の型を付けた行、Arrow の表、ファイルを受け取ります。[メモリ上のデータ](/ja/guides/in-memory/)を参照してください。
- `localTransport` は同じスレッドのエンジンを呼びます。大きな表では、エンジンを Web Worker に置いて `workerTransport` でつなぐと、並べ替えの間もページが止まりません。[ブラウザーで開く大きなファイル](/ja/guides/browser/)を参照してください。

## ブラウザーで開くファイル

メモリエンジンは、利用者が選んだファイルを Web Worker の中で、アップロードせずに読みます。CSV・TSV・JSON Lines・Excel・Parquet のファイルと、HTTP の範囲指定で読む URL の Parquet です。100 万行の CSV は約 1 秒で開きます。Worker とページのコードは[ブラウザーで開く大きなファイル](/ja/guides/browser/)にあります。それをそのまま試せるページが[ファイルを開く](/ja/open/)です。

## サーバーのファイル

```bash
npm install vastgrid vastgrid-duckdb
```

サーバーでは、`DuckDBEngine` が許可したフォルダーの中のファイルを開き、`createHttpHandler` がグリッドの要求に答えます。

```ts
// server.ts
import { createServer } from "node:http";
import { createHttpHandler, DuckDBEngine } from "vastgrid-duckdb";

const engine = await DuckDBEngine.create({
  allowedDirectories: ["/srv/data"],
  tempDirectory: "/tmp/vastgrid",
});

createServer(createHttpHandler(engine, { path: "/api/table" })).listen(8080);
```

ページでは、`httpTransport` がグリッドのメッセージを送ります。`table` は許可したフォルダーの中のファイルです。

```tsx
import { DataGrid, httpTransport } from "vastgrid";
import "vastgrid/styles.css";

const transport = httpTransport("/api/table", { events: "/api/table/events" });

export function Sales() {
  return <DataGrid transport={transport} table="sales/2025.parquet" style={{ height: 600 }} />;
}
```

DuckDB はファイルをその場で読み、ページが受け取るのは表示する行だけです。1 億行の Parquet でも、並べ替えの最初の行は 1 秒以内に表示されます。設定、Fetch API のフレームワーク、Server Functions、サーバーでの最初の行の描画は、[サーバーのファイル](/ja/guides/server/)にあります。
