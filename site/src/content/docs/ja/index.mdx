ブラウザーの中で作った架空の注文 10 万件を、メモリエンジンが持っています。列のメニュー（▾）を開くと並べ替え・絞り込み・グループ化・統計の表示ができ、セルの上をドラッグすると、下にその個数・合計・平均が出ます。⌘/Ctrl ＋ F で検索できます。[デモ](/ja/demo/)ではセルの編集も試せます。[ファイルを開く](/ja/open/)では、手元のファイルをアップロードせずに開けます。

```bash
npm install vastgrid vastgrid-js
```

```tsx
import { DataGrid, localTransport } from "vastgrid";
import "vastgrid/styles.css";
import { memoryEngine } from "vastgrid-js";

const transport = localTransport(
  memoryEngine({
    tables: {
      people: {
        columns: [
          { name: "name", type: "string" },
          { name: "born", type: "integer" },
          { name: "field", type: "string" },
        ],
        rows: [
          ["Ada Lovelace", 1815, "Mathematics"],
          ["Grace Hopper", 1906, "Computer science"],
        ],
      },
    },
  }),
);

export function App() {
  return <DataGrid transport={transport} table="people" style={{ height: 600 }} />;
}
```

ディスク上のファイルは、`vastgrid-duckdb` が Node.js の DuckDB で開きます。[サーバーのファイル](/ja/guides/server/)を参照してください。サーバーがなくても、`vastgrid-js` が利用者の選んだファイルや URL の Parquet を Web Worker の中で読みます。[ブラウザーで開く大きなファイル](/ja/guides/browser/)を参照してください。同じグリッドは、コマンド、VS Code の拡張機能、MCP App、ノートブックのウィジェットとしても使えます。[アプリ](/ja/apps/overview/)を参照してください。

<CardGrid>
  <Card title="どんな大きさでも開ける" icon="document">
    行はスクロールに合わせて、まとまりごとに読みます。サーバーでは 1 億行の Parquet をその場で読み、並べ替えの最初の行を 1 秒以内に表示して、残りはその間に作ります。サーバーがなくても、100 万行の CSV が約 1 秒で開きます。
  </Card>
  <Card title="速い" icon="rocket">
    セルはキャンバスに描き、スクロールでは React を描画しません。スクロール中にフレームを落とさず、矢印キー 1 回で React のコミットは 1 回です。エンジンを Web Worker に置けば、100 万行を並べ替える間もページは止まりません。
  </Card>
  <Card title="表計算ソフトの操作" icon="pencil">
    範囲の選択と Excel のキー操作、コピーと貼り付け、複数の列での並べ替え、AND と OR を組み合わせた絞り込み、すべての列からの絞り込み、検索、統計、グループ化、ピボット、計算列、合計行。
  </Card>
  <Card title="編集と保存" icon="document">
    入力・貼り付け・連続入力・元に戻す・やり直しができ、値はすべて列の型で確かめます。DuckDB のエンジンは、編集していないバイトをそのまま残して CSV と TSV のファイルに保存します。
  </Card>
  <Card title="API はコマンド" icon="puzzle">
    表示の設定は JSON のドキュメント、操作の場所はセッションです。変更はすべて型の付いたコマンドで、グリッドのメニューと同じように、自作の UI、ホスト、AI のエージェントからも送れます。
  </Card>
  <Card title="9 つの言語" icon="translate">
    文言は英語・日本語・中国語・韓国語・スペイン語・ポルトガル語・フランス語・ドイツ語があり、言語ごとに別の import です。CSS 変数によるライトとダーク、ARIA のグリッドの役割、IME での入力を含むキーボードだけでの操作にも対応しています。
  </Card>
</CardGrid>
