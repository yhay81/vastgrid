---
title: グループ化と集計
description: 列で行をグループ化して件数・合計・平均・最小・最大を求める方法と、表の下端の集計行。計算は source が行います。
---

グリッドは、1 つ以上の列で行をグループ化し、グループごとの集計値を表として表示できます。表の下端には集計行も表示できます。どちらも source が計算します（`TableSource.group`）。対象は、現在の絞り込み・条件・検索で残る行です。そのため 1 億行の表でも、ブラウザーに届くのはグループだけです。

| source | グループ化と集計行 |
| --- | --- |
| `ArraySource` | 対応（メモリ上で計算）。 |
| `RemoteSource` ＋ `vastgrid-duckdb` | 対応。列の番号から組み立てた、パラメーターのない 1 つの SQL で計算します。 |
| `BrowserSource`（`vastgrid-browser`） | `fullScan` のとき（ローカルのファイルでは既定）に対応。Worker でファイルを 1 回読んで計算します。 |
| 自作の source | `group` を実装し、`capabilities.group` を返すとき。 |

グリッドは、source が `capabilities.group` を返すときだけこれらの機能を有効にします。

## グリッドでの操作

- **グループ化**：ツールバーの「グループ化」でパネルが開きます。グループ化する列（選んだ順がキーの順）と、集計値（行の件数、または列の件数・合計・平均・最小・最大）を選びます。列の型に合う集計方法だけを選べます。列のメニューの「この列でグループ化」は、その列でグループ化して行を数えます。
- グリッドはグループを表として表示します。キーの列のあとに、集計値ごとに `sum(amount)` のような名前の列が続きます。ツールバーのチップには、何でグループ化したか、先に絞り込んだかどうか、グループの数が出ます。チップの ×（またはパネルの「行の表示に戻す」）で、元の絞り込み・並べ替え・列の設定のまま行の表示に戻ります。
- **集計行**：列のメニューの「下端の集計行に表示…」で、表の下端に固定される行に出す集計方法を選びます。集計値をクリックすると同じメニューが開き、値のコピーもできます。対象は現在のビュー（絞り込み・条件・検索）で、選択範囲ではありません。

## グループの意味

- **対象の行**：現在のビューの行。ビューの並べ替えは関係しません。
- **キー**：null は 1 つのグループになり、空の文字列も別の 1 つのグループになります（SQL と同じく別の値です）。数値は値でまとめます（decimal の列の `1.5` と `1.50` は同じグループ）。リスト・構造体・マップ・バイナリ・JSON・不明な型の列はキーにできません。
- **集計方法**：列を指定しない `count` は行を数え、列を指定するとその列の null でない値を数えます。`sum` と `avg` は数値の列、`min` と `max` は数値・文字列・真偽値・日付・時刻・UUID の列に使えます。null は除き、浮動小数点の列の NaN と無限大も除きます。値がないときの結果は空です（`count` は 0）。
- **順序**：グループはキーの昇順で、空（null と空の文字列）は最後です。グループの表の列で並べ替えると、その列の順（昇順・降順とも空は最後、同じ値はキーの順）になります。
- **型と精度**：`count` は整数です。整数の `sum` は 2^53 を超えても正確な整数です（そのときは文字列で届きます）。decimal の `sum` は列の小数点以下の桁数を保った正確な decimal です。浮動小数点の `sum` とすべての `avg` は浮動小数点数です。`min` と `max` は列と同じ型なので、列の表示形式で表示されます。
- **件数の上限**：読むグループは既定で 1,000 まで（`limit`、最大 100,000）です。それより多いときは、現在の順で先頭のグループを表示し、全体の数を示します。並べ替えると、新しい順の先頭のグループを source から読み直します。
- **統計・絞り込み・検索・書き出し**：グループの表でも、ほかの表と同じく、列の統計、グループの絞り込みと検索、CSV・TSV・JSON・Excel への書き出し（ブラウザーでダウンロード）が使えます。これらはすべてのグループを読めたときだけ有効です。上限より多いときは、並べ替え・検索（⌘F）・選択範囲の集計だけが使えます。
- **行の選択**（`checkboxSelection`）は表の行のものです。グループにはチェックボックスがありません。

## 集計行の扱い

- グリッドの行ではありません。行と一緒に選択・コピー（「集計値をコピー」を除く）・書き出しされることはなく、矢印キーでも移動しません。セルはグリッドの後ろのタブ順にあるボタンなので、Tab キーで移動できます。スクリーンリーダーは列名・集計方法・値を読み上げます。
- 集計値が列の値（合計・最小・最大）のときは列の表示形式で、件数はただの数値で表示します。
- グループの表の集計行は、グループの集計です（`sum` の列の合計は全行の合計、`count(*)` の列の合計は行数）。

## 設定の保存

`getState()` は両方を保存します。

```json
{
  "version": 1,
  "schema": ["region", "product", "amount"],
  "query": { "filters": [{ "type": "compare", "column": 2, "op": "gt", "value": 0 }] },
  "columns": [{ "name": "amount", "total": "sum" }],
  "group": {
    "keys": ["region"],
    "aggregates": [{ "fn": "count" }, { "fn": "sum", "column": "amount" }],
    "state": { "version": 1, "schema": ["region", "count(*)", "sum(amount)"], "query": { "sort": [{ "column": 2, "direction": "desc" }] } }
  }
}
```

- `columns[].total` は、その列の集計行での集計方法です。
- `group` はキーと集計値の列を名前で持ちます。`group.state` はグループの表自体の設定（並べ替え・絞り込み・列幅・集計行）で、列はグループの表の列名で持ちます。`query` と `columns` は行の表示の設定のままで、グループ化を解除するとそれに戻ります。`"group": null` は行の表示です。
- `group` のある状態を適用すると、先にグループを読みます。表にない列は除きます。

## コードから使う

`group` は source のメソッドなので、グリッドなしでも使えます。たとえばグラフを描くときです。

```ts
const view = await source.createView({ filters: [{ type: "compare", column: 2, op: "gt", value: 0 }] });
const result = await source.group({
  view: view.id,
  keys: [0],
  aggregates: [{ fn: "count" }, { fn: "sum", column: 2 }],
  sort: [{ column: 2, direction: "desc" }],
  limit: 20,
});
// result.columns: [{ name: "region", type: "string" }, { name: "count(*)", type: "bigint" }, { name: "sum(amount)", type: "decimal" }]
// result.rows: [["東京", 120, "53210.50"], …], result.groups: 47, result.truncated: true
```

`keys` がないと、結果は全体の集計の 1 行です。`GroupedSource` は結果をそれだけで 1 つの表として見せるので、2 つ目のグリッドや独自の画面に使えます。

```tsx
<DataGrid source={new GroupedSource(source, { keys: [0], aggregates: [{ fn: "count" }], query })} />
```

リクエストと結果の正確な定義は[プロトコル](/ja/reference/protocol/#groups-and-totals)にあります。
