グリッドは表計算ソフトと同じように、ポインターとキーボードで扱えます。ここに書いたことは、すべて[デモ](/ja/demo/)で試せます。操作はどれもグリッドの状態への[コマンド](/ja/reference/commands/)なので、人がポインターでできることは、アプリからも `dispatch` でできます。

ツールバーやメニューに何が出るかは、エンジンによって決まります。エンジンはできることを capabilities（`plan.where`、`plan.aggregate`、`find`、`summarize`、`write`、`export` など）で伝え、グリッドはエンジンができることだけを表示します。[エンジン](/ja/reference/engines/)を参照してください。

## 選択

- セルをクリックするとアクティブになります。ドラッグか Shift ＋ クリックで範囲を選びます。端の外までドラッグするとスクロールします。
- ⌘/Ctrl ＋ クリックで範囲を足せます。コピーはすべての範囲が対象です。
- 行番号の列（ガター）をクリックすると行全体を選び、そのままドラッグすると続く行も選びます。左上の角をクリックするか ⌘/Ctrl ＋ A ですべてを選びます。
- `columnGroups` を指定したときは、グループの見出しをクリックするとその列をまとめて選びます。列名のクリックは列を選ぶのではなく、その列で並べ替えます（[並べ替え](#並べ替え)）。

ステータスバーには、アクティブなセル（`12 行目・price`）を表示します。複数のセルを含む範囲を 1 つ選ぶと、少し後に個数・合計・平均も表示します。計算はエンジンが行うので（`capabilities.summarize`）、100 万行の範囲でもすべての行が対象です。

## キー操作

Apple のプラットフォームでは ⌘、それ以外では Ctrl を使います。

| キー | 操作 |
| --- | --- |
| 矢印・Page Up/Down | アクティブなセルを 1 つ・1 ページ動かす |
| ⌘/Ctrl ＋ 矢印 | 最初・最後の行や列へ移る |
| Home/End・⌘/Ctrl ＋ Home/End | 最初・最後の列へ移る・ビューの最初・最後のセルへ移る |
| Shift ＋ 上のキー | 選択を広げる |
| Tab・Enter（Shift で逆向き） | 右・下へ移る。複数のセルを選んでいるときはその中を動く |
| ⌘/Ctrl ＋ A | すべてを選ぶ |
| ⌘/Ctrl ＋ C | コピー |
| 文字の入力・F2・ダブルクリック | セルを編集する（[セルの編集](/ja/guides/editing/)を参照） |
| Delete・Backspace | 選んだセルを消す |
| ⌘/Ctrl ＋ Z・⌘/Ctrl ＋ Shift ＋ Z（Ctrl ＋ Y） | 元に戻す・やり直す |
| ⌘/Ctrl ＋ D・⌘/Ctrl ＋ R | 下へ・右へコピーする |
| ⌘/Ctrl ＋ S | ファイルに保存する（エンジンが保存できるとき） |
| ⌘/Ctrl ＋ F | 検索（エンジンが検索できるとき） |
| Alt ＋ ↓ | アクティブな列のメニュー |
| Shift ＋ F10・コンテキストメニューのキー・右クリック | セルのメニュー |
| Alt ＋ Enter | 詳細パネルを開く・閉じる |
| Space | アクティブな行のチェックを切り替える（`checkboxes` のとき）、またはリンクやボタンのセルを押す |
| Esc | メニュー・検索バー・エディターを閉じる |

書き込むキーは、書き込めるセルでだけ働きます。エンジンが保存や検索をしないときは、⌘/Ctrl ＋ S と ⌘/Ctrl ＋ F はブラウザーの操作になります。

## コピー

⌘/Ctrl ＋ C は、選んだセルをタブ区切りのテキストと HTML の表の両方でコピーするので、表計算ソフトや文書に貼り付けてもセルが保たれます。コピーに入るのは値のテキスト表記（`2024-01-31`、すべての桁を持つ数値）で、画面で書式を付けた文字や列名は入りません。まだ読み込んでいないセルは読み込んでからコピーします。一度にコピーできるのは 1,000,000 セルまでです。

複数の範囲は表計算ソフトと同じように並べます。行が同じ範囲は横に、列が同じ範囲は縦に、グリッドでの順序で並べ、範囲の間のセルは詰めます。それ以外の組み合わせはコピーせず、そう伝えます（`copy_layout`）。

コードからは、`dispatch({ command: "copy", headers: true })` で、選択範囲を列名付きの `{ tsv, html, markdown }` として受け取れます。

## 並べ替え

- 列名をクリックすると、その列で昇順、もう一度で降順、さらにもう一度で並べ替えなしになります。Shift ＋ クリックで、その列を次の並べ替えキーとして足します。
- 列のメニュー（見出しの右端の矢印、見出しの右クリック、または Alt ＋ ↓）には、昇順に並べ替え、降順に並べ替え、次の順で昇順に並べ替え、次の順で降順に並べ替え、並べ替えを解除があります。
- 空白（null と空の文字列）は昇順・降順とも最後になり、同じ値の行は表の順のままです。並べ方はどのエンジンでも同じです（[§3.3](https://github.com/yhay81/vastgrid/blob/main/docs/spec.md#33-order)）。

並べ替えるのは画面の行ではなく表全体で、エンジンが行います。DuckDB エンジンは 100 万行以上の並べ替えでは先頭の 1,000 行をすぐに表示し、その間に残りを並べ替えます。ビューができあがるまでステータスバーに「ビューを読んでいます…」と表示し、先の行はできた順に表示します。

## 絞り込みと検索

- **検索**（ツールバーの入力欄）は、表のどれかの列がその文字を含む行だけを残します。大文字と小文字は区別しません。
- 列のメニューの **絞り込み…** は、列の値とそれぞれの行数を多い順に一覧し、チェックボックス、「値を検索」、「（すべて選択）」、「（空白）」で選べます。その下では、入力した文字で条件を指定できます。等しい、等しくない、より小さい、以下、より大きい、以上、範囲（下限・上限）、を含む、を含まない、で始まる、で終わる、空白、空白以外です。文字の条件は大文字と小文字を区別せず、値は列の型として読みます。行をグループ化できないエンジンでは、条件だけを指定できます。条件のある列の見出しには、矢印の代わりにじょうごのマークが出ます。
- セルのメニューの **この値で絞り込む** と **この値を除く** は、アクティブなセルの値で絞り込みます。
- ツールバーの **条件**（条件があるときはその数も表示）は、すべての条件を「すべてを満たす（AND）」か「いずれかを満たす（OR）」のグループとして表示し、条件を追加、グループを追加（入れ子にできます）、すべて解除ができます。コードが書いた条件のうちメニューで分解できないものは、式として表示して残します。適用すると条件を置き換え、検索はそのまま残します。

これらはどれもプランの `where` で、ドキュメントに保存されます（[状態](/ja/guides/state/)を参照）。グループ化したビューでは絞り込み…は出ません。グループに対する条件は `having` です（[グループ化](/ja/guides/grouping/)を参照）。

## 表の中の検索

⌘/Ctrl ＋ F でツールバーの下に検索バーが開きます。Enter でアクティブなセルより後にある、入力した文字を含むセルを、Shift ＋ Enter で前のセルを、表示している列から探します。最後まで行くと最初に戻り、見つかったセルがアクティブになります。「大文字と小文字を区別」をオンにしない限り、大文字と小文字は区別しません。Esc で閉じます。ビュー全体をエンジンが探すので、画面から遠いセルも見つかります。

## セルのメニュー

セルの右クリック、Shift ＋ F10、コンテキストメニューのキーで開きます。コピー、この値で絞り込む、この値を除く（グループ化したビューでは出ません）、値の全体を表示（DuckDB エンジンが 2,000 文字を超える文字列を切ったときなど、エンジンが途中で切った文字を読み直します）、詳細があります。

## 列の統計

列のメニューの **統計…** は、ビューの行について、行数、値の数、空、異なる値の数、最小、最大、合計、平均、中央値、標準偏差のうち、列の型に合うものを表示します。エンジンが計算するので、表の大きさにかかわらず正確です。エンジンが行をグループ化でき、ビューがグループ化されていないときに出ます。

## 列の操作

- **幅**：見出しの右端をドラッグします（40 ピクセル以上）。右端をダブルクリックするか、列のメニューの「幅を内容に合わせる」で内容に合わせます。
- **順序**：列名をドラッグします。移る先に線が出ます。列全体を選んでいるときはまとめて動き、グループの見出しをドラッグするとその列がまとめて動きます。列は置いた先の固定に従います。
- **固定**：列のメニューの「左端に固定」「右端に固定」「固定を解除」で、横にスクロールしても列が見えたままになります。
- **非表示**：列のメニューの「列を隠す」で隠し、「すべての列を表示」で戻します。
- ツールバーの **列** は、表示している列を順に並べ、それぞれに隠すためのチェックボックスと左右へ動かすボタンを付けます。その後に隠した列、「列を検索」の入力欄、「すべての列を表示」が続きます。
- 列のメニューの **書式…** では、見出しの表示名、配置、折り返し、数値（数値・パーセント・通貨、小数点以下の桁数、桁区切り）、日付の形式、条件付きの色（条件、文字の色、背景の色、色の意味）を設定します。「書式を解除」で外せます。コピーとエディターは値のまま扱い、書き出しは表示名を見出しに使い、Excel ファイルには数値の書式も付けます。

どれもコマンド（`column.resize`、`column.move`、`column.pin`、`column.hide`、`column.show`、`column.format`）で、ドキュメントに保存されます。

列のメニューの「集計行…」で表の下端に集計行を足し、「この列でグループ化」で行の代わりにグループを表示します。[グループ化と集計](/ja/guides/grouping/)を参照してください。ツールバーの計算列メニューで計算する列を足し（[計算列](/ja/guides/formulas/)）、書き出しメニューでファイルに書き出します（[書き出し](/ja/guides/export/)）。

## チェックした行と詳細パネル

- `checkboxes` を指定すると、ガターに行ごとのチェックボックスが、左上の角にビューのすべての行のチェックボックスが出ます。チェックボックスか Space で、アクティブな行をチェックします。チェックはレコード（キー）に付くので、並べ替えや絞り込みをしても残り、ステータスバーにチェックした行の数が出ます。いまの絞り込みではチェックの状態が分からない行にはダッシュが出て、絞り込みをチェックしたときに戻すまでチェックできません。
- ツールバーの **詳細** か Alt ＋ Enter で、グリッドの横（グリッドの幅が 640 ピクセル未満なら下）にパネルが開きます。アクティブな行のすべての列を、隠した列も含め、表示名と書式を付けて、文字を省略せずに表示し、アクティブなセルに付いて動きます。`detailPanel` プロパティで、行を自作のコンポーネントで表示できます。[DataGrid](/ja/reference/data-grid/) を参照してください。
