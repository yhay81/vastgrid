グリッドは表計算ソフトと同じように、マウスと Excel のキー操作で扱えます。ここに書いたことは、すべて[デモ](/ja/demo/)で試せます。

## 選択

- セルをクリックするとアクティブになります。ドラッグか Shift ＋ クリックで範囲を選びます。
- ⌘/Ctrl ＋ クリックで範囲を足せます。集計とコピーは、すべての範囲が対象です。
- 列見出しをクリックするとその列を、行見出しをクリックするとその行を、左上の角をクリックするとすべてを選びます。見出しの上をドラッグすると、いくつもまとめて選べます。
- `checkboxSelection` を指定すると、行ごとのチェックボックスでも行を選べます。並べ替えや絞り込みをしても同じレコードが選ばれたままです（[行の選択](/ja/reference/data-grid/#行の選択チェックボックス)）。Shift ＋ クリックで範囲を選べます。

ステータスバーには、アクティブなセルを表示します。複数のセルを選んだときは、空白でないセルの個数（データの個数）と、数値なら合計・平均・最小・最大も表示します。並べ替えや絞り込みをしたビューでは、ファイルでの行の位置も表示します。

## キー操作

| キー | 操作 |
| --- | --- |
| 矢印・Page Up/Down・Home/End | アクティブなセルを動かす |
| ⌘/Ctrl ＋ 矢印・⌘/Ctrl ＋ Home/End | 最初・最後の行や列へ移る |
| Shift ＋ 上のキー・Shift ＋ クリック | 選択を広げる |
| ⌘/Ctrl ＋ クリック | 範囲を足す |
| Tab・Enter（Shift で逆向き） | 選択の中を動く |
| Shift ＋ Space・Ctrl ＋ Space・⌘/Ctrl ＋ A | 行・列・すべてを選ぶ |
| Space・⌘/Ctrl ＋ Shift ＋ Space（`checkboxSelection` のとき） | アクティブな行・すべての行のチェックを切り替える |
| ⌘/Ctrl ＋ C・⌘/Ctrl ＋ Shift ＋ C | コピー・見出しを含めてコピー |
| ⌘/Ctrl ＋ F | 検索 |
| Alt ＋ ↓ | 列のメニュー（並べ替え・絞り込み・統計・固定・非表示） |
| F2・ダブルクリック | セルの値の全体を表示 |
| Alt ＋ Enter（もう一度でパネルへ）・Esc | アクティブな行の詳細パネルを開く・閉じる |
| Shift ＋ F10・コンテキストメニューのキー・右クリック | セルのメニュー（コピー・この値で絞り込む・並べ替え） |
| Esc | メニューやパネルを閉じる・読み込み中のコピーを取り消す |

## コピー

⌘/Ctrl ＋ C は、選択範囲をタブ区切りのテキストと HTML の表の両方でコピーするので、表計算ソフトや文書に貼り付けてもセルが保たれます。⌘/Ctrl ＋ Shift ＋ C は列名も含めてコピーし、セルのメニューでは「Markdown の表としてコピー」も使えます。画面では途中で切れているセルも、コピーには値の全体が入ります。一度にコピーできるのは、すべての範囲を合わせて `copyLimit` 個（既定で 1,000,000 個）のセルまでです。[列の表示設定](/ja/reference/data-grid/#列の表示設定)で書式を付けた列も、`copyValues` を `"formatted"` にしない限り、表示上の文字ではなく値をコピーします。

複数の範囲は Excel と同じようにまとめてコピーします。行が同じ範囲は横に、列が同じ範囲は縦に並べます。どちらもグリッドでの順序（ビューの行の順、表示している列の順で、非表示の列は含めない）を保ち、範囲の間の行や列は詰め、範囲が重なるセルは 1 回だけコピーします。それ以外の範囲の組み合わせはまとめてコピーできないので、コピーせずにそう伝えます。まだ読み込んでいないセルは読み込んでからコピーし、読み込み中のコピーは Esc で取り消せます。

## 並べ替え

列のメニューは、ポインターを載せた見出しに出る ▾ か、Alt ＋ ↓ で開きます。ここで昇順・降順に並べ替えられます。「次の順で昇順に並べ替え」と「次の順で降順に並べ替え」は、その列を次の並べ替えのキーに加え、複数の列で並べ替えます。このとき、見出しにはキーの順番が表示されます。空白のセルは、表計算ソフトと同じく、昇順でも降順でも最後に並びます。

ソースが並べ替えの途中で結果を示せるとき（DuckDB のサーバーは 100 万行以上の表で示します）は、先頭の行がすぐに表示され、ツールバーに「並べ替えています… ○ 行のうち先頭の 1,000 行を表示中」と出ます。スクロールと選択はどこでもできます。その先の行は並べ替えが終わるまで読み込み中と表示し、終わると表示します。先頭の行は動きません。それまでは、先頭の行より先を含むコピーと検索は待つよう伝え、選択範囲の集計は「…」と表示し、絞り込んだビューの統計は使えません。

## 絞り込み

- **値で。** 列のメニューの「絞り込み…」では、その列の値が件数とともに多い順に並び、値を検索する欄もあります。チェックを外した値は除かれます。
- **条件で。** 同じパネルで、数値は比較や範囲で、文字列は「を含む」「で始まる」「で終わる」などで（「大文字と小文字を区別」も選べます）、どの列も「空白」「空白以外」で絞り込めます。
- **セルから。** セルのメニューの「この値で絞り込む」「この値を除く」で、そのセルの値に絞り込むか、その値を除けます。
- **AND・OR の条件で。** 列の絞り込みパネルの「条件を追加（AND）…」「条件を追加（OR）…」で、その絞り込みと新しい条件を入れた条件の組み立て画面が開きます（たとえば「地域が東京 *または* 売上が10万超」）。ツールバーの「条件…」では、すべての絞り込みを入れた画面が開きます。グループは、すべての条件に合う行（AND）か、どれかの条件に合う行（OR）を残します。グループは入れ子にでき、同じ列に複数の条件を付けられます。値を入れていない条件は、適用するときに除かれます。
- **すべての列から。** ツールバーの検索欄は、どれかの列にその文字列を含む行だけを残します。大文字と小文字は区別しません。

複数の列の絞り込みは、すべて同時に効きます。ツールバーには、それぞれの絞り込みと AND・OR の条件が解除のボタンとともに表示され、残った行の数も表示されます。条件をクリックすると変更できます。条件で使っている列は、見出しに絞り込みの印が付きます。統計・選択範囲の集計・コピー・書き出しは、残った行に対して行います。条件を評価できない source（`capabilities.conditions`）では、組み立て画面は使えません。

## 表の中の検索

⌘/Ctrl ＋ F で検索のバーが開きます。Enter でその文字列を含む次のセルへ、Shift ＋ Enter で前のセルへ移ります。アクティブなセルから、1 行の中を列の順に見て、次の行へと探します。検索はアクティブなセルを動かすだけで、表示する行は変えません。行を絞るには、ツールバーの検索欄を使ってください。

## 列の統計

列のメニューの「列の統計」は、行数、空白と値の種類の数、最小と最大を表示し、数値なら平均・標準偏差・四分位・分布、文字列なら最短と最長の文字数も表示します。多い値の一覧もあります。

## 書き出し

ツールバーの「書き出し」で、現在のビュー（絞り込み・並べ替えのとおり）か表全体を、表示中の列かすべての列で、source に応じて CSV・TSV・Parquet・JSON・Excel に書き出します。[書き出し](/ja/guides/export/)を参照してください。

## 列

- 見出しの端をドラッグすると、列の幅を変えられます。端をダブルクリックするか「幅を内容に合わせる」を使うと、列の幅を値に合わせます。
- 選んだ列の見出しをドラッグすると、列を動かせます。
- アプリが列をグループにまとめているときは、グループの見出し（列名の上）をクリックするとその列を選び、選んだグループの見出しをドラッグすると列をまとめて動かせます。
- 「この列までを固定」は、横にスクロールしても、その列までを左に固定します。「この列から右端までを固定」は、その列から最後の列までを右に固定します。ツールバーの「列」パネルでは、列ごとに左・右・なしを選べます。右に固定した列は、左の端をドラッグして幅を変えます。
- 「列を隠す」で列を隠せます。ツールバーの「列」ボタンには、すべての列が並び、表示・非表示を切り替えられます。
- F2 かダブルクリックで、セルの値の全体を改行も含めて表示します（「値の全体を表示」）。
- Alt ＋ Enter か、セルのメニューの「行の詳細を表示」で、グリッドの横（狭いときは下）に詳細パネルを開きます。アクティブな行のすべての列を全体で表示し、セルを動かすと追従します。もう一度 Alt ＋ Enter でパネルへフォーカスを移し、Esc で閉じます。
