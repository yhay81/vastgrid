The grid is one package, and the data comes from an engine. Pick the engine by where the data is:

| Package | Contents |
| --- | --- |
| [`vastgrid`](https://www.npmjs.com/package/vastgrid) | `DataGrid`, `GridProvider` and the hooks for React. `vastgrid/core` has the store and the transports without React, and `vastgrid/server` reads the first rows on a server. |
| [`vastgrid-js`](https://www.npmjs.com/package/vastgrid-js) | The memory engine, in the page or in a Web Worker: rows in JavaScript, Arrow tables, CSV, TSV, JSON Lines and Excel files, and Parquet files on disk or at a URL. |
| [`vastgrid-duckdb`](https://www.npmjs.com/package/vastgrid-duckdb) | The DuckDB engine for Node.js, for files of any size, with a handler for HTTP. |
| [`vastgrid-spec`](https://www.npmjs.com/package/vastgrid-spec) | The specification as code: types, commands, plan checking and the conformance tests. For your own engine. |
| [`vastgrid-sql`](https://www.npmjs.com/package/vastgrid-sql) | Plans as DuckDB SQL, for an engine of your own on DuckDB. |

The same grid also comes ready to use, with no code: a command (`npx vastgrid-cli data.parquet`), a VS Code
extension, an MCP App for chats and a widget for Jupyter notebooks. See [Apps](/apps/overview/).

## Requirements

- **`vastgrid`**: React 19.3 or later, and a browser with the CSS `light-dark()` function: Chrome and Edge 123,
  Firefox 120, Safari 17.5 or later. React is needed only for `DataGrid` and the hooks; `vastgrid/core` and
  `vastgrid/server` run without it.
- **`vastgrid-js`**: the same browsers, with module workers to run it in a Web Worker, or Node.js 20 or later.
- **`vastgrid-duckdb`**: Node.js 20 or later, on a platform DuckDB's Node.js bindings ship for: Linux (x64 or
  arm64, glibc or musl), macOS (x64 or arm64) or Windows (x64 or arm64).

## Data in memory

```bash
npm install vastgrid vastgrid-js
```

Make the engine and its transport once, outside the component, and give the grid the name of a table and a
height:

```tsx
import { DataGrid, localTransport } from "vastgrid";
import "vastgrid/styles.css";
import { memoryEngine } from "vastgrid-js";

const transport = localTransport(
  memoryEngine({
    tables: {
      people: {
        columns: [
          { name: "name", type: "string" },
          { name: "born", type: "integer" },
          { name: "field", type: "string" },
        ],
        rows: [
          ["Ada Lovelace", 1815, "Mathematics"],
          ["Grace Hopper", 1906, "Computer science"],
        ],
      },
    },
  }),
);

export function App() {
  return <DataGrid transport={transport} table="people" style={{ height: 600 }} />;
}
```

- The grid fills its parent's height, or the height you give it. It draws only the rows on screen.
- The memory engine takes rows with their columns' types, Arrow tables and files: see
  [Data in memory](/guides/in-memory/).
- `localTransport` calls the engine in the same thread. For a large table, run the engine in a Web Worker with
  `workerTransport` so that sorting never stops the page: see [Large files in the browser](/guides/browser/).

## A file in the browser

The memory engine reads a file that a person picks, in a Web Worker, without uploading it: CSV, TSV, JSON Lines,
Excel and Parquet, and Parquet files at a URL by HTTP ranges. A million-row CSV file opens in about a second.
[Large files in the browser](/guides/browser/) has the worker and the page. [Open a file](/open/) is that page,
ready to try.

## Files on a server

```bash
npm install vastgrid vastgrid-duckdb
```

On the server, `DuckDBEngine` opens the files under the folders you allow, and `createHttpHandler` answers the
grid's requests:

```ts
// server.ts
import { createServer } from "node:http";
import { createHttpHandler, DuckDBEngine } from "vastgrid-duckdb";

const engine = await DuckDBEngine.create({
  allowedDirectories: ["/srv/data"],
  tempDirectory: "/tmp/vastgrid",
});

createServer(createHttpHandler(engine, { path: "/api/table" })).listen(8080);
```

In the page, `httpTransport` posts the grid's messages, and `table` is a file under an allowed folder:

```tsx
import { DataGrid, httpTransport } from "vastgrid";
import "vastgrid/styles.css";

const transport = httpTransport("/api/table", { events: "/api/table/events" });

export function Sales() {
  return <DataGrid transport={transport} table="sales/2025.parquet" style={{ height: 600 }} />;
}
```

DuckDB reads the file where it is, and the page receives only the rows it shows. A 100-million-row Parquet file
shows its first sorted rows in under a second. [Files on a server](/guides/server/) covers the options,
frameworks with the Fetch API, Server Functions and rendering the first rows on the server.
