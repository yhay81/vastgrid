Every color, font and size is a CSS custom property on `.vg-root`, the grid's root element. The canvas reads
them too, so a few lines of CSS restyle the cells, the headers, the menus and the panels alike:

```css
.my-app .vg-root {
  --vg-font-family: "Inter", sans-serif;
  --vg-bg: var(--surface);
  --vg-fg: var(--text);
  --vg-accent: var(--brand);
  --vg-selection-bg: color-mix(in srgb, var(--brand) 15%, transparent);
}
```

Each of these presets is a class with a handful of properties
([their CSS](https://github.com/yhay81/vastgrid/blob/main/site/src/styles/docs.css)), passed to the grid as
`className`, and some with a `rowHeight`:

## Light and dark

The colors are `light-dark()` pairs, and the stylesheet gives `.vg-root` `color-scheme: light dark`, so the grid
follows the system's light or dark mode. That declaration has no specificity, and any `color-scheme` of yours on
`.vg-root` replaces it:

```css
/* Always light. */
.vg-root {
  color-scheme: light;
}

/* Follow the page's own switch. */
:root[data-theme="light"] .vg-root {
  color-scheme: light;
}
:root[data-theme="dark"] .vg-root {
  color-scheme: dark;
}
```

In your own colors, use `light-dark()` the same way, or set the properties under your dark theme's selector.
Keep a `color-scheme` on `.vg-root`: bundlers that turn `light-dark()` into variables for older browsers
(Lightning CSS, which Vite uses) need it, and without one the canvas draws black.

## When the canvas reads them

The canvas reads the properties:

- when the grid mounts, and when web fonts finish loading;
- when the `class`, `style` or `data-theme` attribute of the page's `<html>` or `<body>` changes (and
  `data-jp-theme-light`, which JupyterLab sets);
- when the grid's own `className` or `style` changes;
- when the system switches between light and dark;
- when `rowHeight`, `headerHeight`, `columnGroups` or `groupHeaderHeight` change.

## Sizes

Row and header heights come from `--vg-row-height` and `--vg-header-height`, or from the `rowHeight` and
`headerHeight` props, which win. Rows of a column that wraps its text are `wrapLines` lines high (2 by default),
each `--vg-line-height` high. Column groups take `--vg-group-header-height` per row of groups, or
`groupHeaderHeight`.

Below 640 pixels wide, the grid puts the detail panel under the rows, `--vg-detail-height` high, instead of
beside them, `--vg-detail-width` wide.

[`styles.css`](https://github.com/yhay81/vastgrid/blob/main/packages/grid/src/styles.css) has the exact values,
and the class names of the toolbar, status bar, menus and panels for further changes. To change one cell's
colors, not the theme, use `cellStyle` or a column's conditional styles: see [DataGrid](/reference/data-grid/).
