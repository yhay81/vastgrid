Every color, font and size is a CSS custom property on `.vg-root`, the grid's root element. The canvas
reads them too, so a few lines of CSS restyle the cells, the headers, the menus and the panels alike:

```css
.my-app .vg-root {
  --vg-font-family: "Inter", sans-serif;
  --vg-bg: var(--surface);
  --vg-fg: var(--text);
  --vg-accent: var(--brand);
  --vg-selection-bg: color-mix(in srgb, var(--brand) 15%, transparent);
}
```

Each of these presets is a class with a handful of properties
([their CSS](https://github.com/yhay81/vastgrid/blob/main/site/src/styles/docs.css)), passed to the grid
as `className`:

## Light and dark

The default colors use `light-dark()`, so they follow the `color-scheme` of the page or of any element
around the grid. Set `color-scheme: light`, `dark` or `light dark` where your app chooses its theme, and
the grid follows, also when it changes while the grid is open. In your own colors, use `light-dark()`
the same way, or set the properties under your dark theme's selector.

In forced-colors mode (Windows high contrast), the grid uses the system colors.

## When the grid reads them

The grid reads the properties when it mounts, when its `className` or `style` change, when the
`class`, `style` or `data-theme` attribute of the document's root element changes, and when the
system's color scheme changes. To restyle it in another way, change its `className`.

Row and header heights are read when the grid mounts. To change them later, pass `rowHeight`,
`headerHeight` and `groupHeaderHeight`.

## Properties

| Property | Light | Dark | Use |
| --- | --- | --- | --- |
| `--vg-font-family` | `system-ui, …` | | Every text |
| `--vg-font-size` | `13px` | | Cells; headers and menus derive from it |
| `--vg-row-height` | `24px` | | Row height, unless `rowHeight` is given |
| `--vg-line-height` | 1.4 × font size | | Height of each further line in columns that wrap |
| `--vg-header-height` | `32px` | | Height of the row of column names, unless `headerHeight` is given |
| `--vg-group-header-height` | `24px` | | Height of each row of column groups, unless `groupHeaderHeight` is given |
| `--vg-radius` | `6px` | | Corners of inputs, buttons, menus and panels |
| `--vg-bg` | `#ffffff` | `#16161a` | Cells |
| `--vg-fg` | `#1f2328` | `#e6e6eb` | Text |

[`styles.css`](https://github.com/yhay81/vastgrid/blob/main/packages/react/src/styles.css) has the exact
values, and the class names of the toolbar, status bar, menus and panels for further changes.
