100,000 made-up orders, generated in your browser and held by the memory engine. Open a column's menu (▾) to
sort, filter, group or see its statistics, drag across cells to see their count, sum and average below, and
press ⌘/Ctrl+F to find. The [demo](/demo/) edits cells too, and [Open a file](/open/) opens a file of yours
without uploading it.

```bash
npm install vastgrid vastgrid-js
```

```tsx
import { DataGrid, localTransport } from "vastgrid";
import "vastgrid/styles.css";
import { memoryEngine } from "vastgrid-js";

const transport = localTransport(
  memoryEngine({
    tables: {
      people: {
        columns: [
          { name: "name", type: "string" },
          { name: "born", type: "integer" },
          { name: "field", type: "string" },
        ],
        rows: [
          ["Ada Lovelace", 1815, "Mathematics"],
          ["Grace Hopper", 1906, "Computer science"],
        ],
      },
    },
  }),
);

export function App() {
  return <DataGrid transport={transport} table="people" style={{ height: 600 }} />;
}
```

For files on disk, `vastgrid-duckdb` opens them with DuckDB in Node.js: see [Files on a server](/guides/server/).
With no server, `vastgrid-js` reads the files a person picks, and Parquet files at a URL, in a Web Worker: see
[Large files in the browser](/guides/browser/). The same grid also comes as a command, a VS Code extension, an
MCP App and a notebook widget: see [Apps](/apps/overview/).

  <Card title="Any size" icon="document">
    Rows are read as you scroll, a block at a time. On a server, a 100-million-row Parquet file is read in

  <Card title="Fast" icon="rocket">

    are sorted.
  </Card>
  <Card title="A spreadsheet's way of working" icon="pencil">

  </Card>
  <Card title="Edit and save" icon="document">
    Type, paste, fill, undo and redo, with every value checked against its column's type. The DuckDB engine
    saves CSV and TSV files with every byte you did not edit kept as it was.
  </Card>
  <Card title="Commands are the API" icon="puzzle">
